# Background

Customizes the dashboard background image, animation mode, static color, and pattern overlay.

> Settings area: `background`
> Dashboard documentation route: `/docs/settings-background`

## What This Area Is For

Customizes the dashboard background image, animation mode, static color, and pattern overlay. This page expands the short Settings-page help text into an operator reference for deciding when to change this area, what behavior the controls affect, and what to verify after saving.

Use it when you are configuring a new project, auditing inherited settings, or debugging behavior that changed after a system, project, or sprint override was saved.

## Controls And Runtime Effect

Image upload, animated/static mode, animation style, color picker, and overlay pattern shape the visual layer behind panels.

| Control Surface | Runtime Effect | Review Before Saving |
| --- | --- | --- |
| Image Upload | Sets a custom background image behind dashboard panels. | Large images may affect dashboard load performance. |
| Animated/Static Mode | Toggles background animation effects. | Static mode is recommended if motion is distracting. |
| Color Picker / Pattern | Sets a solid color or overlay pattern if no image is used. | Ensure contrast with dashboard text and panels. |

## Recommended Configuration

Prefer lightweight images and readable contrast; use static mode if motion is distracting.

Prefer lightweight images and readable contrast; use static mode if motion is distracting or impacts dashboard rendering performance.

## Risks And Gotchas

Large images and busy patterns can hurt performance or reduce text contrast, making the dashboard difficult to read.

## Troubleshooting

If the dashboard is sluggish, switch to a solid color or static mode. If text is unreadable, adjust the color picker for better contrast.
